# factor-lab

一个 A 股因子研究的脚手架，目标是让"用到未来信息"这件事变得困难。

> **免责声明：本项目仅供研究与教学使用，不构成任何投资建议。**

## 当前状态

早期开发中，尚无可用功能。包结构、测试框架和文档骨架已就位，核心逻辑待实现。

## 为什么做这个

做 A 股因子研究时，大多数代码在以下地方埋着隐性错误。这些错误不会报错，只会让回测结果看起来比实际好得多。

**前复权价格做滚动计算。** 前复权会把除权日之后的价格调整反映到历史数据上。这带来三个问题：第一，今天的前复权序列是用截至今天的全部除权信息倒推的，因此任何依赖价格绝对值的逻辑都在使用未来信息。举例：筛选"股价低于 10 元"时，一只 2020 年实际 30 元、2023 年三送一的股票，在前复权序列里 2020 年显示为 10 元，会被错误选入。第二，涨跌停判定必须使用不复权原始价，用复权价会判错。第三，可复现性问题：每次发生新的除权，整段历史被重写，同一份回测代码在不同时间运行会得到不同结果。

**财报按报告期对齐。** 年报的报告期是 12 月 31 日，但实际公告可能在次年 4 月。如果在 2023 年 12 月 31 日就用到了年报数据，等于提前 4 个月知道了财报内容。这种信息泄露会让因子看起来有预测能力，实际上只是提前看到了未来。

**幸存者偏差。** 回测时只用当前还在上市的股票，等于自动排除了所有退市公司。这些恰恰是表现最差的股票，排除它们会让回测收益系统性偏高。

**涨跌停当日假设可成交。** 涨停时买单排队但未必能成交，跌停时卖单同理。如果策略在涨停日"买入"，实际上是在用不可能成交的价格计算收益。这种虚假成交对高换手策略的影响远大于低换手策略，可能贡献收益的主要部分。

**新股上市首日纳入选股池。** 新股上市初期波动极大，且存在大量非理性定价。如果回测从上市首日就开始计算收益，会混入这段异常波动，让因子看起来有预测能力。

**成分股名单未时点化。** 用当前的指数成分股列表回测历史，等于提前知道了哪些公司未来会被纳入。纳入前后通常伴随资金流入和涨幅。这与幸存者偏差是两个独立问题，前者关于指数成员资格，后者关于是否退市。

## 快速开始

```bash
git clone https://github.com/whitewhatpin/factor-lab.git
cd factor-lab
uv sync --all-extras
uv run pytest
```

目前只有冒烟测试，验证包结构可以正常导入。核心功能实现后会补充端到端 demo。

## v0.1 打算做什么

- 数据层：Tushare → DuckDB 的增量落地，含交易日历、行情、财务、状态表
- 因子层：声明式因子定义接口，横截面去极值 / 标准化 / 市值与行业中性化
- 评估层：IC / ICIR / 分层回测 / 换手率 / 基础图表报告
- 示例：动量、市值、估值三个经典因子作为端到端 demo

上述陷阱在 v0.1 中的处理状态：财报公告日对齐 → v0.1 内；成分股名单时点化 → v0.1 内；复权方式显式选择 → v0.1 内；选股池时点化（停牌/退市/ST/新股） → v0.1 内；涨跌停成交约束 → 推迟到 v0.2。

明确不做：实盘对接、订单管理、机器学习模型、Web UI。
